# 语音机器人运行控制能力 PRD

## 一、需求目标

在现有机器人配置中补充打断控制、工具运行控制、触发器接口调用及变量赋值、上下文压缩和播放进度自动跟随能力。前端仅保留客户需要配置的内容，后台算法参数由平台维护。

## 二、功能范围

| 模块 | 配置位置 | 前端配置 |
|---|---|---|
| 打断控制 | 机器人配置 → 对话策略 | 灵敏度、有效短回复词、强制打断词、多条打断后话术 |
| 工具运行控制 | 工具配置 → 新建或编辑工具 | 重复调用、用户打断后、进度反馈、最大执行时间、暂停静默计时 |
| 调用接口 | 机器人配置 → 触发器 | 接口、请求参数映射、返回值映射、等待音、超时、失败处理 |
| 上下文压缩 | 机器人配置 → 基础配置 → LLM 配置 | 开启或关闭 |
| 播放进度自动跟随 | 通话记录 → 通话详情 | 点击播放后自动定位并高亮对应话轮 |

## 三、详细需求

### 3.1 打断控制

#### 3.1.1 打断灵敏度

前端提供“灵敏、平衡、稳健”三档。后台只维护最短有效语音和最少有效字数两个参数：

| 灵敏度 | 最短有效语音 | 最少有效字数 |
|---|---:|---:|
| 灵敏 | 200ms | 1字 |
| 平衡 | 350ms | 2字 |
| 稳健 | 600ms | 3字 |

普通打断同时满足两个条件后才停止机器人播报。有效字数统计前去掉标点和空格。

#### 3.1.2 有效短回复词

客户可以配置“是、对、嗯、好、行”等短词。

ASR结果与配置词完全一致时：

1. 绕过最短有效语音和最少有效字数限制。
2. 作为完整用户回复。
3. 允许打断机器人并进入后续流程。

本期不由话轮模型判断短词在不同Step中的语义，配置什么就按什么执行。不提供“忽略短词”配置。

#### 3.1.3 强制打断词与话术

客户可以配置“停、等一下、先别说”等强制打断词，并配置多条打断后话术。

命中后只执行：

1. 立即停止当前TTS。
2. 从打断后话术列表中选择一条播放。
3. 重新进入聆听状态。

该模块不判断挂断、转人工或其他业务意图，相关判断由对应模块负责。强制打断词不受灵敏度限制。

#### 3.1.4 判断顺序

1. 命中强制打断词：立即打断并播放打断后话术。
2. 命中有效短回复词：作为完整回复。
3. 其他内容：按当前灵敏度的语音时长和有效字数判断。
4. 未达到阈值：沿用现有不完整话轮处理。

### 3.2 工具运行控制

#### 3.2.1 重复调用保护

相同通话内，相同工具使用相同参数重复调用时，支持：

- 复用结果。
- 等待原任务。
- 拒绝重复。

#### 3.2.2 用户打断后

普通新问题打断工具时，支持：

- 取消执行。
- 后台继续。
- 静默继续。

取消、修改查询条件、转人工和挂机等明确意图由对应业务模块判断，不在本配置中重复判断。

#### 3.2.3 进度反馈

客户可以配置：

- 首次反馈时间。
- 后续反馈间隔。
- 等待反馈话术，多条话术轮流播放。
- 最大执行时间。
- 执行期间暂停静默计时。

达到首次反馈时间仍未返回结果时播放第一条等待话术；之后按反馈间隔轮流播放。工具结束或达到最大执行时间后停止进度反馈。

开启暂停静默计时后，工具执行期间不触发静默提醒和静默挂机。

### 3.3 调用接口

触发器统一使用“调用接口”动作。接口的触发时机由“通话开始/通话结束”决定；当触发时机为通话开始时，即可用于前置数据拉取。

#### 3.3.1 接口与请求参数

- 从已配置的API工具中选择接口，不直接填写接口ID。
- 请求参数通过“接口参数 → 来源变量”进行映射。

#### 3.3.2 返回值赋值

返回值映射包含：

| 配置项 | 说明 |
|---|---|
| 返回字段 | 接口结果中的字段路径，例如 `data.orderId` |
| 通话变量 | 从机器人变量配置中选择目标变量 |
| 默认值 | 返回字段为空时使用的值 |
| 必填 | 必填字段为空时按失败处理执行 |

接口成功后先完成变量赋值，再进入欢迎语或首个Step。

#### 3.3.3 等待与失败

支持配置等待音、超时时间和失败处理。失败处理包括继续通话、转人工和结束通话。

### 3.4 上下文压缩

在“基础配置 → LLM配置”增加“上下文压缩”开关。

开启后，通话历史达到后台阈值时，将较早话轮整理为摘要，仅保留近期原始话轮和关键业务事实。前端不配置压缩轮次、Token阈值、摘要模型或压缩算法。

### 3.5 播放进度自动跟随

1. 用户点击AI通话播放按钮后，播放器开始推进进度。
2. 系统根据真实音频播放时间自动高亮对应话轮。
3. 当前话轮离开可视区域时自动滚动到该话轮。
4. 点击某条对话时，录音跳转到对应时间并继续播放。
5. 振铃音不参与对话定位。

## 四、旧配置兼容

| 配置 | 默认值 |
|---|---|
| 打断灵敏度 | 平衡 |
| 有效短回复词 | 是、对、嗯、好、行 |
| 强制打断词 | 停、等一下、先别说 |
| 打断后话术 | 好的，您请说。 |
| 工具重复调用 | 复用结果 |
| 用户打断后 | 取消执行 |
| 首次反馈时间 | 3秒 |
| 后续反馈间隔 | 8秒 |
| 最大执行时间 | 30秒 |
| 执行期间暂停静默计时 | 开启 |
| 上下文压缩 | 关闭 |

旧配置缺少新增字段时按默认值展示，页面能够正常打开和保存。

## 五、验收标准

1. 打断控制只展示灵敏度、有效短回复词、强制打断词和多条打断后话术，不展示忽略短词。
2. 工具运行控制可以保存和回显重复调用、打断后、进度反馈和静默计时配置。
3. 调用接口可以选择API工具并配置请求参数和返回值变量映射。
4. LLM配置展示“上下文压缩”开关。
5. 点击AI通话播放按钮后，进度自动推进并跟随高亮对话。
6. 点击对话后，播放进度跳转并继续播放。
7. 旧配置打开和保存不报错。
