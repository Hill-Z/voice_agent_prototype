# 综合运营报表需求与统计口径文档

3\. 全局筛选口径

### 3.1 筛选项

| 筛选项  | 页面形态                        | 影响范围   |
| ---- | --------------------------- | ------ |
| 时间范围 | 今日 / 昨日 / 本周 / 上周 / 本月 / 上月 | 全部模块   |
| 机器人  | 多选下拉                        | 全部模块   |
| 呼叫方向 | 全部呼叫 / 呼入 / 外呼              | 全部模块   |
| 刷新   | 按钮                          | 全部模块   |
| 导出   | 按钮                          | 当前筛选结果 |

### 3.2 时间范围定义

| 选项 | 统计范围                       |
| -- | -------------------------- |
| 今日 | 当天 00:00 到当前时间             |
| 昨日 | 昨天 00:00 到昨天 24:00         |
| 本周 | 本周一 00:00 到当前时间            |
| 上周 | 上周一 00:00 到上周日 24:00       |
| 本月 | 本月 1 日 00:00 到当前时间         |
| 上月 | 上月 1 日 00:00 到上月最后一天 24:00 |

### 3.3 全局分母原则

- 页面所有“占比”必须写清分母，不能只写百分比。
- 通话类占比默认分母是当前筛选范围内的 `通话总量`。
- Flow 完成率分母是当前 Flow 的 `进入量`。
- Step / 边明细的分母只在本 Flow 内计算，不跨 Flow 混算。
- 工具成功率分母是当前工具的 `调用次数`。

## 4. 数据事件来源建议

正式后端建议至少提供以下事件或宽表。前端不直接扫原始日志，由后端按筛选条件聚合后返回。

| 数据来源        | 关键字段                                                                                                                                                                                      | 用途                            |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| 通话记录 / CDR  | `callId`, `botId`, `callDirection`, `startedAt`, `answeredAt`, `endedAt`, `duration`, `status`, `hangupBy`, `hangupReason`, `customerPhone`, `region`                                     | 通话总量、接通率、有效通话率、时长、地域、挂断原因、短通话 |
| Topic 识别事件  | `callId`, `topicId`, `topicName`, `occurredAt`, `isFirstTopic`                                                                                                                            | Topic 命中通话数、主题占比、首次主题占比       |
| Flow 事件     | `callId`, `flowId`, `flowName`, `botId`, `eventType`, `eventTime`                                                                                                                         | Flow 进入量、完成量、平均流程时长           |
| Step 事件     | `callId`, `flowId`, `stepId`, `stepName`, `stepType`, `enterTime`, `exitTime`                                                                                                             | Step 进入量、平均停留时长               |
| Edge / 分支事件 | `callId`, `flowId`, `edgeId`, `fromStepId`, `toStepId`, `edgeType`, `conditionText`, `eventTime`                                                                                          | 边命中次数、命中占比                    |
| 转人工事件       | `callId`, `flowId`, `stepId`, `reason`, `eventTime`                                                                                                                                       | 转人工量、Step 转人工量                |
| 工具调用事件      | `callId`, `botId`, `flowId`, `stepId`, `toolId`, `toolName`, `toolType`, `startedAt`, `endedAt`, `status`, `latencyMs`, `failureReason`, `directPlay`, `modelReplyUsed`, `savedModelCall` | 工具调用、成功率、耗时、失败原因、直接播报和模型节省    |

## 5. 页面结构与统计模块

页面从上到下分三块：

```text
综合运营报表
├─ 顶部筛选：日期 / 机器人 / 呼叫方向 / 导出 / 刷新
├─ 通话统计
├─ 业务与流程分析
│  ├─ Topic 主题分析
│  └─ Flow 流程分析
│     ├─ Step 明细弹窗
│     └─ 边 / 分支明细弹窗
└─ 工具调用
```

## 6. 通话统计

### 6.1 顶部指标卡

| 指标      | 页面展示               | 含义                | 计算公式                                                               | 分母    | 备注                                                                                |
| ------- | ------------------ | ----------------- | ------------------------------------------------------------------ | ----- | --------------------------------------------------------------------------------- |
| 通话总量    | 数量                 | 当前筛选范围内所有呼入和外呼通话数 | `count(distinct callId)`                                           | 无     | 包含接通、未接、失败、异常等所有发起记录                                                              |
| 接通率     | 百分比                | 有接通的通话占比          | `接通通话数 / 通话总量`                                                     | 通话总量  | 接通通话建议用 `answeredAt is not null` 或 `status in (answered, completed, transferred)` |
| 有效通话率   | 百分比 + “时长 >15 秒”说明 | 超过有效时长阈值的通话占比     | `count(callId where duration > 15s) / 通话总量`                        | 通话总量  | 15 秒是当前页面口径，可配置化                                                                  |
| 平均通话时长  | 时长                 | 接通通话的平均通话时长       | `avg(duration where answeredAt is not null)`                       | 接通通话数 | 展示为“X分Y秒”                                                                         |
| 转人工量    | 数量 + 转人工率          | 当前筛选范围内触发人工转接的次数  | `count(transfer_event)`                                            | 无     | 转人工率 = `转人工量 / 通话总量`                                                              |
| 重复呼入客户  | 数量 + 占比            | 当前筛选范围内多次呼入的客户数   | `count(distinct customerPhone where inbound_call_count > 1)`       | 无     | 占比 = `重复呼入客户数 / 通话总量`；若后端更偏客户视角，可另给“占客户数比例”                                       |
| 用户主动挂断量 | 数量 + 占比            | 用户侧主动结束通话的数量      | `count(callId where hangupBy = user)` 或 `count(user_hangup_event)` | 无     | 占比 = `用户主动挂断量 / 通话总量`；依赖网关能区分用户挂断和系统超时                                            |

### 6.2 通话量趋势

通话量趋势是折线 / 面积图，横轴按时间聚合。

| 时间范围              | 聚合粒度 |
| ----------------- | ---- |
| 今日 / 昨日           | 小时   |
| 本周 / 上周 / 本月 / 上月 | 日期   |

趋势图会跟随顶部“呼叫方向”切换两条线的含义：

| 呼叫方向 | 蓝线   | 绿线    | 计算公式                                                                                 |
| ---- | ---- | ----- | ------------------------------------------------------------------------------------ |
| 全部呼叫 | 总通话数 | 有效通话数 | 蓝线：`inbound + outbound`；绿线：`count(duration > 15s)`                                   |
| 呼入   | 呼入量  | 有效接待量 | 蓝线：`count(callDirection = inbound)`；绿线：`count(inbound and duration > 15s)`           |
| 外呼   | 外呼量  | 接通量   | 蓝线：`count(callDirection = outbound)`；绿线：`count(outbound and answeredAt is not null)` |

业务原因：呼入是用户主动来电，不重点看“有没有拨通”，更适合看“是否有效接待”；外呼是系统主动拨打，才重点看接通结果。

### 6.3 挂断 / 未接通原因

| 字段   | 含义                              | 计算公式                                      |
| ---- | ------------------------------- | ----------------------------------------- |
| 原因名称 | 正常结束、用户主动挂断、接通前放弃、超时、异常中断、无人接听等 | 后端归一化后的 `hangupReason`                    |
| 数量   | 该原因出现次数                         | `count(callId where hangupReason = 当前原因)` |
| 占比   | 该原因占全部通话比例                      | `数量 / 通话总量`                               |

注意：如果网关不能可靠区分“用户主动挂断”和“静默超时后系统挂断”，需要把该字段标记为低可信，或合并到“超时”。

### 6.4 通话时长分布

| 字段   | 含义                                    | 计算公式                                   |
| ---- | ------------------------------------- | -------------------------------------- |
| 时长区间 | 0-10秒、10-30秒、30-60秒、1-3分钟、3-5分钟、5分钟以上 | 按 `duration` 分桶                        |
| 数量   | 落入该区间的通话数                             | `count(callId where duration in 当前区间)` |
| 占比   | 该区间占全部通话比例                            | `数量 / 通话总量`                            |
| 完成率  | 该区间内业务完成占比                            | `count(completed_call in 区间) / 区间通话数`  |
| 转人工率 | 该区间内转人工占比                             | `count(transfer_event in 区间) / 区间通话数`  |

### 6.5 地域分析

| 字段  | 含义       | 计算公式                                |
| --- | -------- | ----------------------------------- |
| 地域  | 省份或城市    | `region`                            |
| 呼叫量 | 当前地域通话数  | `count(callId where region = 当前地域)` |
| 接通率 | 当前地域接通占比 | `接通通话数 / 当前地域通话数`                   |

地域分析只展示呼叫量和接通率，不展示完成率，避免把流程或业务结果错误归因到地域。

### 6.6 时段热力图

| 字段  | 含义         | 计算公式                                    |
| --- | ---------- | --------------------------------------- |
| 星期  | 周一到周日      | `weekday(startedAt)`                    |
| 小时  | 0-23 点     | `hour(startedAt)`                       |
| 通话量 | 某星期某小时的通话数 | `count(callId where weekday + hour 命中)` |

颜色深浅按当前筛选结果内最大格子的通话量做相对归一化，不跨筛选条件比较颜色。

### 6.7 重复呼入 TOP 客户

| 字段       | 含义                  | 计算公式 / 来源                                                                   |
| -------- | ------------------- | --------------------------------------------------------------------------- |
| 客户号码     | 脱敏手机号               | `mask(customerPhone)`                                                       |
| 24小时呼入次数 | 最近 24 小时同一客户呼入次数    | `count(inbound call where customerPhone = 当前客户 and startedAt >= now - 24h)` |
| 7天呼入次数   | 最近 7 天同一客户呼入次数      | `count(inbound call where customerPhone = 当前客户 and startedAt >= now - 7d)`  |
| 最近业务     | 最近一次通话关联业务          | 最近通话的 `businessName`                                                        |
| 最近结果     | 最近一次通话结果            | 最近通话的 `result`                                                              |
| 未解决次数    | 未完成 / 失败 / 转人工未闭环次数 | `count(call where result in unresolved)`                                    |
| 最近呼入时间   | 最近一次呼入时间            | `max(startedAt)`                                                            |

表格交互：支持搜索、排序、分页、每页条数切换。搜索建议匹配客户号码、最近业务、最近结果。

### 6.8 短通话样本

| 字段    | 含义              | 计算公式 / 来源             |
| ----- | --------------- | --------------------- |
| 通话 ID | 样本通话唯一 ID       | `callId`              |
| 客户号码  | 脱敏手机号           | `mask(customerPhone)` |
| 时长    | 通话时长            | `duration`            |
| 挂断方   | 用户 / 系统 / 未知    | `hangupBy`            |
| 挂断原因  | 秒挂、静默超时、未说话、误拨等 | `hangupReason`        |
| 机器人   | 关联机器人           | `botName`             |
| 业务    | 最近业务            | `businessName`        |
| 最近节点  | 挂断前最后一个节点       | `lastNode`            |

默认筛选短通话：`duration < 30s`。表格支持搜索、排序、分页。点击“查看”时，正式系统应跳转到通话记录详情。

## 7. 业务与流程分析

业务与流程分析分成两个表：Topic 和 Flow。

- Topic 回答“用户在聊什么”。
- Flow 回答“流程跑得怎么样”。

这两个口径不能混在一张表里，否则会误导用户把转人工、挂断等流程结果归因到某个 Topic。

### 7.1 Topic 主题分析

| 字段      | 含义                          | 计算公式                                               | 分母   |
| ------- | --------------------------- | -------------------------------------------------- | ---- |
| 主题      | 用户需求主题名称                    | `topicName`                                        | 无    |
| 命中通话数   | 出现过该主题的通话数；同一通话多次出现同一主题只算一次 | `count(distinct callId where topicId = 当前主题)`      | 无    |
| 主题占比    | 该主题覆盖多少通话                   | `命中通话数 / 通话总量`                                     | 通话总量 |
| 首次主题通话数 | 该主题是通话第一个主题的通话数             | `count(distinct callId where firstTopicId = 当前主题)` | 无    |
| 首次主题占比  | 该主题作为首个需求的占比                | `首次主题通话数 / 通话总量`                                   | 通话总量 |

Topic 表不展示：完成率、转人工量、主动挂断量、趋势、代表原话、最高卡点步骤。原因是这些都属于流程或质检口径，不属于纯需求分布。

表格交互：

- 默认按命中通话数降序。
- 支持主题名称搜索。
- 支持点击表头排序。
- 支持分页和每页条数切换。
- 搜索无结果时展示空状态。

### 7.2 Flow 流程分析

| 字段      | 含义                      | 计算公式                                                       | 分母             |
| ------- | ----------------------- | ---------------------------------------------------------- | -------------- |
| Flow 名称 | 流程名称                    | `flowName`                                                 | 无              |
| 机器人     | Flow 所属机器人              | `botName`                                                  | 无              |
| 进入量     | 进入该 Flow 的次数            | `count(flow_start_event where flowId = 当前 Flow)`           | 无              |
| 完成率     | 完成该 Flow 的占比            | `count(flow_completed_event where flowId = 当前 Flow) / 进入量` | 当前 Flow 进入量    |
| 平均流程时长  | 从进入 Flow 到离开 Flow 的平均时长 | `avg(flow_exit_time - flow_start_time)`                    | 已离开 Flow 的执行实例 |
| 明细      | 打开 Step 明细或边 / 分支明细     | 前端交互                                                       | 无              |

当前前端 Demo 的平均流程时长是把节点平均停留时长相加得到近似值；正式后端必须直接用 Flow 实例的进入和退出时间计算。

Flow 表不展示：到达结束节点量、中途离开量、下一步到达量、下一步到达率。原因是主表只保留流程级核心指标，细节进入弹窗看。

表格交互：

- 默认按进入量降序。
- 支持 Flow 名称 / 机器人搜索。
- 支持点击表头排序。
- 支持分页和每页条数切换。
- 明细按钮打开单层弹窗，不在表格里套大块卡片。

### 7.3 Step 明细弹窗

Step 明细只统计当前 Flow 内部的步骤表现。

| 字段      | 含义                   | 计算公式                                              | 分母                 |
| ------- | -------------------- | ------------------------------------------------- | ------------------ |
| Step 名称 | 步骤名称                 | `stepName`                                        | 无                  |
| Step 类型 | 开始、采集、工具、结束等         | `stepType`                                        | 无                  |
| 进入量     | 进入该 Step 的次数         | `count(step_enter_event where stepId = 当前 Step)`  | 无                  |
| 平均停留时长  | 用户或系统停留在该 Step 的平均时长 | `avg(step_exit_time - step_enter_time)`           | 当前 Step 有退出时间的进入实例 |
| 转人工量    | 在该 Step 触发转人工的次数     | `count(transfer_event where stepId = 当前 Step)`    | 无                  |
| 用户挂断量   | 在该 Step 用户主动挂断的次数    | `count(user_hangup_event where stepId = 当前 Step)` | 无                  |

弹窗交互：

- 搜索 Step 名称 / 类型。
- 支持列排序。
- 表头固定，表格在弹窗内部滚动。
- 支持分页和每页 8 / 15 / 30 条切换。
- 搜索无结果时显示“当前搜索没有命中的 Step”。
- 点击遮罩、关闭按钮或按 Esc 关闭。

### 7.4 边 / 分支明细弹窗

边 / 分支明细用于看用户从一个 Step 走向另一个 Step 的路径。

| 字段      | 含义              | 计算公式                                       | 分母          |
| ------- | --------------- | ------------------------------------------ | ----------- |
| 起点 Step | 连线来源步骤          | `fromStepName`                             | 无           |
| 终点 Step | 连线目标步骤          | `toStepName`                               | 无           |
| 分支类型    | 普通连线、条件分支、大模型分支 | `edgeType`                                 | 无           |
| 条件说明    | 该分支的触发条件        | `conditionText`                            | 无           |
| 命中次数    | 该边被走过的次数        | `count(edge_hit_event where edgeId = 当前边)` | 无           |
| 命中占比    | 该边在起点 Step 下的占比 | `命中次数 / 起点 Step 进入量`                       | 起点 Step 进入量 |

弹窗交互：

- 搜索起点、终点、条件说明和分支类型。
- 支持列排序。
- 表头固定，表格在弹窗内部滚动。
- 支持分页和每页 8 / 15 / 30 条切换。
- 搜索无结果时显示“当前搜索没有命中的边或分支”。

## 8. 工具调用

工具调用只展示工具稳定性和性能，不再混入单独的转人工分析。整体转人工数据已放入通话统计指标卡。

| 字段        | 含义                          | 计算公式                                                 | 分母       |
| --------- | --------------------------- | ---------------------------------------------------- | -------- |
| 工具名称      | 工具或函数名称                     | `toolName`                                           | 无        |
| 关联机器人     | 当前筛选范围内使用该工具的机器人数量          | `count(distinct botId where toolId = 当前工具)`          | 无        |
| 类型        | API、SMS、TRANSFER、FUNCTION 等 | `toolType`                                           | 无        |
| 调用次数      | 当前筛选范围内工具调用总次数              | `count(tool_call_event where toolId = 当前工具)`         | 无        |
| 成功率       | 工具调用成功占比                    | `successCount / callCount`                           | 当前工具调用次数 |
| 平均耗时      | 工具调用平均响应时长                  | `avg(latencyMs)`                                     | 当前工具调用次数 |
| 超时次数      | 工具调用超时次数                    | `count(tool_call_event where status = timeout)`      | 无        |
| 直接播报次数    | 工具结果直接播报给用户的次数              | `count(tool_call_event where directPlay = true)`     | 无        |
| 直接播报成功率   | 直接播报成功占比                    | `directPlaySuccessCount / directPlayCount`           | 直接播报次数   |
| 调模型回复次数   | 工具结果交给模型整理回复的次数             | `count(tool_call_event where modelReplyUsed = true)` | 无        |
| 节省模型次数    | 工具结果无需再次调模型的次数              | `count(tool_call_event where savedModelCall = true)` | 无        |
| 失败原因 TOP1 | 当前工具最常见失败原因                 | `top1(failureReason by count)`                       | 无        |

表格交互：

- 默认按调用次数降序。
- 支持工具名称、类型、失败原因搜索。
- 支持点击表头排序。
- 支持分页和每页条数切换。
- 失败原因 TOP1 单独成列，不能塞进工具名称单元格。

## 10. 页面通用交互要求

| 能力   | 适用范围                          | 要求                                |
| ---- | ----------------------------- | --------------------------------- |
| 加载态  | 全页和各模块                        | 切换筛选、刷新时显示骨架，不出现空白闪屏              |
| 空状态  | 所有表格                          | 当前筛选或搜索无结果时说明原因                   |
| 搜索   | Topic、Flow、Step、边、重复呼入、短通话、工具 | 搜索改变后页码回到第 1 页                    |
| 排序   | 主要表格                          | 点击表头切换降序 / 升序，默认按最重要指标降序          |
| 分页   | 可能增长的表格                       | 展示总条数、当前范围、页码、上一页、下一页             |
