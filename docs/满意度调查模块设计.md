# 满意度调查模块设计

## 1. 目标

在一通电话结束前完成客户评价，并把问卷、机器人、原通话和报表串成完整链路。首版覆盖大多数电话客服场景，不将问卷分数与大模型推断的情绪混为同一指标。

## 2. 产品层级

```text
全局问卷 → 机器人绑定 → 通话结束前触发 → 原通话保存结果 → 跨机器人报表
```

- 问卷是全局资产，可供多个机器人复用。
- 机器人只配置是否启用及使用哪份已发布问卷，不配置调查比例和评价归属。

## 两种调查类型

- 语音智能体：由当前机器人在通话结束前逐项询问，支持评分、单选和开放回答。
- IVR：引用「IVR 管理」中的已发布流程，由 IVR 播放问题并接收 DTMF 按键；旧版满意度 IVR 可直接关联，保持历史配置兼容。
- 每个评价项目独立定义选项和按键，同一项目内按键不能重复，不同项目可以使用不同按键。
- 采集结果统一保存为“问卷版本、评价项目、标准选项值、原始输入”，报表先按项目分别汇总，再计算问卷级完成率和标准指标，不能把不同量表直接求平均。
- 每次调查都固定问卷版本，后续修改问卷不会改变历史结果。
- 调查结果保存在原 Call ID 下，不生成一条无法追溯来源的独立通话。

## 3. 调查类型

### IVR 按键

- 播放开场白和问题，客户通过 DTMF 回答。
- 支持评分题和单选题，不支持开放语音回答。
- CSAT 使用 1–5；NPS 使用 0–10，输入 10 后以 `#` 确认。

### 语音智能体

- 原机器人准备挂机时进入调查流程，完成后再挂机。
- 评分题支持直接说出分数或按键。
- 开放题使用语音回答，保存原文，并由大模型聚合主题和情绪。
- 低分可自动追问原因，追问结果不改变主量表分数。

## 4. 指标与问题

- **CSAT**：1–5 分；4–5 分人数 ÷ 有效评分人数。
- **NPS**：0–10 分；推荐者 9–10，中立者 7–8，贬损者 0–6；NPS = 推荐者占比 − 贬损者占比。
- **自定义**：评分、单选、开放回答，可配置多个问题。

每份问卷包括名称、采集方式、指标、语言、状态、版本、开场白、结束语、无输入提示、重问次数和问题列表。

## 5. 状态与数据口径

- 问卷状态：草稿、已发布、已停用。
- 调查状态：已发起、进行中、已完成、已跳过、中途退出、采集失败。
- 只有已完成且分数有效的回答进入 CSAT/NPS 计算。
- 问卷已有结果后不能删除，只能停用；被机器人使用时必须先解除绑定。

## 6. 报表

筛选条件包括日期、机器人、问卷、指标、调查结果和关键词。核心内容包括：

- 调查触发数、完成率、CSAT、NPS。
- CSAT 评分分布、NPS 人群分布和趋势。
- 机器人与问卷对比。
- 开放回答主题、情绪、占比和代表原文。
- 调查明细，可下钻到原 AI 通话记录。

## 7. 竞品取舍

- 采用 PolyAI 的“通话结束前进入 Voice CSAT”方式，调查不中断原通话链路。
- 采用 Kore.ai 的全局问卷、CSAT/NPS、低分追问和反馈报表结构。
- 采用 Genesys 的独立问卷资产与语音流程分层，避免把问题硬写在机器人提示词里。
- 采用 ElevenLabs 的主题发现与情绪聚合思路分析开放回答，同时保留原始回答下钻。
- Sierra 的公开资料更偏质量监控与洞察，没有公开到可直接复用的满意度问卷配置细节，因此未硬套其页面。
