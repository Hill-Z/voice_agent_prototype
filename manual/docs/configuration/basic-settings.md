# 基础配置

## 机器人新建

在机器人配置页面可以新增机器人，需要填写机器人的名称以及描述。

![机器人新建页面](pathname:///docs/img/新增配置.png)

机器人搭建部分包含以下模块：
- 基础配置
- 意图技能
- 对话策略
- 变量配置
- 业务分析
- 模型调试
- 知识检索配置

![配置页面](pathname:///docs/img/配置页面.png)

## 大模型配置

基础配置包括大模型配置、TTS 配置、ASR 配置以及主要提示词部分的配置。

大模型配置可以选择使用自己的模型或平台提供的模型，目前支持的模型包括：
- 千问 Plus
- 千问 3.5 Plus  
- 千问 3 Max

目前推荐使用千问 Plus 以及千问 3.5 Plus。温度以及采样参数保持默认设置即可。

## TTS 语音配置

### 厂商选择

目前 TTS 支持多家厂商及自研音色：
- **自研音色**：沃丰国风，目前支持中文
- **MiniMax**：支持中文、英文、粤语等小语种，包含 speech2.6 和 speech2.8 两个模型

### 音色设置

音色选项包括音量、语速等参数：
- **MiniMax 音色**：支持调整音量、语速以及情绪
- **自研音色**：不支持这些参数调节，保持默认或情绪设置为空即可

### 自动语种跟随

在 TTS 配置模块有一个自动语种跟随功能。当客户可能说多种语言（中文、粤语、英文）时，可以配置音色映射表，使机器人根据客户语言选择相应音色回复。

### MiniMax 模式说明

MiniMax TTS 音色有两种模式：

| 模式 | 说明 |
|------|------|
| 自动模式 | 根据大模型输出语种自动识别并朗读，适合多语种场景 |
| 指定模式 | 按指定语种朗读，效果更精准，适合单语种确定的场景 |

## ASR 语音识别配置

### 厂商选择

目前支持的 ASR 厂商包括：
- 沃丰自研
- 火山引擎
- 阿里
- 腾讯
- AWS（海外语种优先）

### 模型选择

**推荐配置**：
- 中文：腾讯 8K 中文大模型
- 粤语：腾讯粤语大模型
- 海外语种：AWS 或腾讯小语种模型（印尼语、英语等）

### 模型类型

ASR 模型分为两类：
1. **指定语种模型**：只能识别单一语种（如中文、英文）
2. **混合免切换模型**：支持多语种混合识别，无需指定语种

**混合模型推荐**：
- 腾讯中英粤混合模型：支持中文、英文、粤语混说
- 腾讯多语种识别大模型：支持日语、韩语、英语等多种语言

### 参数设置

#### 允许被打断
机器人在朗读过程中，客户可以打断并提问。

#### VAD 静音时长

VAD（Voice Activity Detection）语音活动检测，用于判断客户说话结束的判别时长。

- 默认值：500ms
- 推荐范围：500ms - 650ms
- 调整建议：若客户说话间隔较大，可适当调长此参数，避免机器人误判打断客户

## 多语言能力构建

结合 MiniMax 自动模式音色和腾讯多语种混合免切换识别模型，可以构建多语言能力的语音机器人。

## 提示词配置

大部分场景可通过提示词撰写实现语音机器人业务流程。提示词包含以下基础模块：

1. **角色设定**：定义机器人角色身份
2. **输出格式约束**：规范输出格式
3. **机器人对话流程**：定义对话逻辑
4. **特殊情况处理**：异常场景处理
5. **ASR 识别异常处理**：识别错误时的处理策略

### 变量引用

提示词支持插入动态变量，这些变量来自外呼任务联系单导入的客户信息（如客户身份、订单号、年龄等）。
