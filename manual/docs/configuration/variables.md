# 变量配置

变量配置分为三种类型：输入变量、对话变量以及提取变量。

## 输入变量

输入变量是外呼任务导入的客户基础信息。

在外呼任务新建联系单时，可以支持客户自定义字段上传订单号、卡类型、会员类型等基础信息。

需要在输入变量配置处添加相应变量，变量名称建议与联系单自定义字段名称保持一致。

## 变量唯一性

所有变量名称必须唯一，在输入变量、对话变量和提取变量中不可重复。

## 对话变量

对话变量是对话过程中通过调用接口或其他方式产生的临时变量。

### 系统变量

系统提供预设变量，可直接引用：
- 通话时长
- 客户性别
- 联系方式
- 通话开始时间

## 提取变量

提取变量用于通话结束后的信息提取。

### 配置要求
- 定义变量名称
- 添加变量描述
- 指定变量数据类型

### 提取原理

信息提取通过通话结束后的通话录音转写的 ASR 文本，从完整对话记录中提取所需信息。
