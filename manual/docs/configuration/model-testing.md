# 模型调试

模型调试模块支持通过语音或文本渠道进行测试。

## 测试方式

### 文本测试
直接点击文本测试按钮进行测试。

### 语音测试
需要配置中继号，使用实际电话进行测试。

**前提条件**：租户已配置可用的中继号。

## 测试注意事项

所有调整的配置生效时间会有 5 分钟缓存延迟。

## 测试功能

### 流程测试
与机器人对话，验证流程和回复是否符合预期。

### 触发来源显示
测试时会显示每条回复是由 LLM 触发还是对话策略触发。

### 延迟数据分析
测试结束后显示各环节耗时数据：
- ASR 耗时
- TTS 耗时
- LLM 耗时
