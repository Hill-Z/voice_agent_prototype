# 业务分析

业务分析模块包含两个标签页：标签管理和信息提取。

## 标签管理

标签管理包括内置标签和自定义标签。

### 意向标签

内置意向标签包括：
- 明确意向
- 明确拒绝
- 用户忙
- 拨打失败
- 无效客户

### 情绪标签

情绪标签用于识别客户情绪，例如开心、生气等。这些标签通过大模型基于通话记录文本进行判断。

### 自定义标签

支持创建自定义标签，每个标签需包含：
- 标签名称
- 标签描述（即提示词）

**示例**：创建"问题已解决"和"问题未解决"两个标签，提示词可写为："判断客户问题是否已解决，已解决打标签'已解决'，未解决打标签'未解决'"。

## 信息提取

信息提取用于与第三方系统对接，可选择接口配置方案，如调用外部接口或系统内置的创建工单接口。

### 提取变量配置

在信息提取配置中选择之前在变量配置中定义的提取变量（如退款原因、退款结果），并为每个变量编写描述（即提示词）。提取逻辑通过大模型提示词实现。
