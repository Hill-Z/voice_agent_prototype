# 高级设置

## 接口管理

接口管理可进行接口新建操作，目前支持的接口类型包括：
- 第三方接口
- 内置工单相关接口

### 接口配置规范
接口配置需按照以下规范设置：
- 请求类型
- 鉴权方式
- URL 参数
- 请求体
- 返回值

### 工单创建配置

工单创建需要配置相应环境（如 S1、S2）的 URL：
1. 采用 POST 请求
2. 替换相应域名
3. 使用客服系统超管账户登录，在账户管理安全中心获取授权 Token

## 问答对管理

问答对管理支持手动或文件批量上传问答对。

### 问答对结构
每个问答对包含：
- 标准问题分类
- 相似问
- 答案

### 使用要求
问答对需要提前生成音频后才能使用，启用后生效。

**特点**：问答对匹配上后直接播放音频，可快速回复。

## 知识发现模块

知识发现通过对话记录抽取可能遇到的各种问题，可选择采纳或忽略答案。

## 词库管理

词库管理可增加垂直领域知识词条，词条有两方面用途：
1. 提供给 LLM，让大模型了解领域知识
2. 作为热词提供给 ASR，提高领域识别准确率

## 工具配置

支持配置 LLM 使用的工具，包括内置工具和第三方工具。
