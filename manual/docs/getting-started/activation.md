# 快速开始

欢迎使用语音智能体平台！本指南将引导您快速完成智能体的构建与上线。

## 整体流程

```
需求分析 → 创建智能体 → 配置开发 → 测试迭代 → 上线部署
```

---

## 步骤 1: 需求沟通与分析

在开始之前，明确以下核心需求：

| 维度 | 常见选项 |
|------|----------|
| **语言支持** | 单语种 / 多语种 / 方言 |
| **业务场景** | 呼入服务 / 外呼任务 |
| **需求类型** | 简单场景/复杂流程/知识密集型（需文档） |
| **业务流程** | 详细业务流程及后续处理 |

**关键问题：**
- 目标用户群体是谁？
- 主要业务目标是什么？
- 是否需要与现有系统对接？

---

## 步骤 2: 创建智能体

1. 登录系统，进入「机器人配置」
2. 点击「新建」
3. 填写基本信息：名称、描述
4. 保存并进入配置页面

---

## 步骤 3: 配置开发

根据需求配置智能体：

### 编写提示词
定义智能体的角色、行为规则和话术风格等

### 基础配置
- 选择大模型、TTS 音色、ASR 模型
- 配置对话策略（开场白、转人工、挂机等）
- 设置变量（输入变量、对话变量、系统变量）

### 进阶配置
- **知识库配置**: 上传或关联文档
- **外部接口**: 配置 API 调用，实现系统集成
- **流程搭建**: 设计对话流程逻辑

---

## 步骤 4: 测试迭代

1. 使用模型调试进行对话/文本测试
2. 验证业务流程、ASR准确性、TTS 朗诵正确性等
3. 根据测试反馈调整提示词和相关配置项
4. 重复测试直到达到预期效果

---

## 步骤 5: 上线部署


### 上线操作
1. 正式环境配置智能体
2. 确认中继号、路由等配置项
3. 智能体进入运行状态

### 监控运维
- 实时监控对话状态
- 查看统计报表
- 查询日志信息
