# 术语表

## 基础术语

### ASR
**Automatic Speech Recognition** - 自动语音识别  
将语音信号转换为文本的技术，是语音交互的基础技术之一。

### TTS
**Text-to-Speech** - 文本转语音  
将文本转换为自然语音输出的技术，支持多种音色、语速和语调调节。

### VAD
**Voice Activity Detection** - 语音活动检测  
检测音频流中是否存在语音的技术，用于判断用户是否正在说话，是实现实时对话的关键组件。

### IVR
**Interactive Voice Response** - 交互式语音应答  
一种自动电话系统，允许来电者通过按键或语音输入与系统交互，常见于呼叫中心场景。

### LLM
**Large Language Model** - 大语言模型  
基于海量文本数据训练的大型深度学习模型，具备理解、生成和推理自然语言的能力，是智能对话的核心引擎。

### KCS
**Knowledge Center Service** - 知识库服务  
提供知识存储、检索和智能问答功能的服务，支持文档解析、语义匹配等能力。

### DTMF
**Dual-Tone Multi-Frequency** - 双音多频  
通过两种不同频率的音频信号组合来传输数字信息的技术，常用于电话按键输入（如拨打分机、选择菜单）。

### Barge-in
**打断功能**  
允许用户在机器人说话过程中打断并插话的功能，提升对话的自然性和交互效率。

### Turn Taking
**话轮检测**  
检测对话中发言者切换的技术，确保在合适的时机进行语音交互的切换，避免说话重叠或沉默。

### MCP
**Model Context Protocol** - 模型上下文协议  
用于管理和传递对话上下文信息的协议，确保模型能够理解对话历史并维持连贯的对话状态。

### RAG
**Retrieval-Augmented Generation** - 检索增强生成  
结合信息检索与生成模型的技术，先从知识库中检索相关信息，再基于检索结果生成回答，提升回答的准确性和可溯源性。

## 功能术语

### 并发数
同时处理的通话数量上限，反映系统的负载能力。

### 意图识别
识别用户话语意图的技术，将用户的自然语言转换为系统可理解的意图标签。

### 转人工
将对话转接给人工坐席的功能，用于处理机器人无法解决的复杂问题。

### 话术
机器人使用的回复文本或语音内容，支持动态变量替换和条件分支。

### 提示词
指导大模型行为和输出格式的指令文本，是控制模型输出的关键手段。

### 变量
用于动态替换话术内容的占位符，支持输入变量、对话变量和系统变量。

### 标签
用于标记通话状态或用户特征的分类标识，便于后续分析和统计。

### 联系单
包含待外呼联系人信息的列表，支持批量导入和状态管理。

## 技术参数

### 温度参数
控制大模型输出随机性的参数，值越高输出越随机，值越低输出越确定性。

### 采样策略
大模型生成文本时的采样方法，如贪婪搜索、随机采样、Top-K 采样等。

### 静音时长
VAD 判定用户说话结束的静音时间阈值，默认 500ms，可根据实际场景调整。

### 并发控制
限制同时进行的通话数量，防止系统过载，保障服务稳定性。

### 置信度阈值
判断意图识别或知识检索结果可靠性的阈值，低于阈值时可触发转人工或追问。
