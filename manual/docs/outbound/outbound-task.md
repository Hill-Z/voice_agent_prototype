# 外呼任务

## 新建外呼任务

点击新建外呼任务，进入新建外呼任务页面。

### 任务设置
- 选择外呼模板
- 输入任务名称
- 选择机器人话术

### 启动方式

**手动启动**：任务创建后为已暂停状态，需要手动开启任务。

**定时启动**：任务创建后在设定时间点启动，启动后任务的启动方式更新为手动启动。

**周期启动**：任务创建后在设定日期区间内的固定时间点每天启动。

### 任务结束时间
可设置日期时间点，超过该时间点任务变为"已过期"状态。

### 无联系人自动停止

- **勾选**：联系人列表及重试拨打结束后，任务变为"已停止"状态
- **不勾选**：联系人列表及重试拨打结束后，任务变为"已暂停"状态
- **默认**：不勾选

### 联系单配置

**拨号设置**：同新建外呼模板。

**呼叫选项**：同新建外呼模板。

### 任务编辑限制

**不可编辑项**：外呼模板、机器人话术、启动方式、拨号设置、重试选项

**可编辑项**：任务名称、备注、任务结束时间、任务优先级、任务选项、联系人表单、主叫号码、任务执行时间、并发数、呼叫有效性

## 任务状态说明

### 开启
开始外呼任务，对未执行号码按顺序呼叫。

### 暂停
暂停外呼任务，正在拨出的外呼需完成后暂停，任务状态为"暂停中"。

开启已暂停的任务，将对任务中的**未执行号码**按顺序呼叫。

### 停止
完全停止外呼任务，正在拨出的外呼需完成后停止，任务状态为"停止中"。

停止外呼任务后将重置所有任务统计信息。

开启已停止的任务，将对任务中的**所有号码**按顺序执行呼叫。
