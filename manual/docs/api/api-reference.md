# API 参考

本章节将介绍语音智能体的 API 接口文档。

## 概述

语音智能体提供 RESTful API 接口，支持与第三方系统集成。

## 接口分类

- **智能体管理接口**：创建、查询、更新、删除智能体
- **对话接口**：发起对话、获取对话历史
- **任务管理接口**：创建、查询外呼任务
- **数据统计接口**：获取通话统计数据

## 认证方式

所有 API 请求需要携带有效的认证 Token。
